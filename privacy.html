Privacy policy

rclone homelab is a personal backup tool used only by its owner. It has no other users.

What it accesses

  • It uses Google's drive.file permission (https://www.googleapis.com/auth/drive.file). That only lets it see and change the files it created itself, in its owner's own Google Drive.
  • Those files are encrypted backups of the owner's own home server. They're encrypted on the owner's computer before upload.

What it does with it

  • It stores and retrieves the owner's backups. Nothing else.
  • It collects no data about anyone. It does not sell, share or transfer Google user data to anyone.
  • Google user data is not used to develop, improve or train artificial intelligence or machine learning models.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the app's access at any time at myaccount.google.com/permissions. Deleting the backup folder in Google Drive deletes everything the app stored.
